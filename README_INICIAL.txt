⚠️ SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

Problema: "Python/npm no encontrado"
→ Solución: Instala Node.js y Python desde sus webs oficiales

Problema: "Puerto 3000/8000 en uso"
→ Solución: Ejecuta opción 6 del script para limpiar

Problema: "No puedo conectar al backend"
→ Solución: Verifica que Django esté en http://localhost:8000

Problema: "Login no funciona"
→ Solución: Ejecuta python run_seeds.py en el backend

Problema: "npm install falla por espacio"
→ Solución: Usa node start-dev-server.js en lugar de npm start

Para más ayuda:
→ Lee: INICIO_RAPIDO.md
→ Lee: QUICK_START.md (en CondoSmart-Frontend/)
